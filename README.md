# zip358.net

**小さく試して、つくるを学ぶ。**

zip358.netは、HTML・CSS、JavaScript、PHPなどを学習できるWebサイトです。コードを読んで、動かして、少しずつ自分のものに。これからWebづくりを始める方が、自分のペースで学べる場所を目指しています。

## 学べること

- **HTML・CSS**：文章や画像を配置し、色やレイアウトを整える、Webページの基本。
- **JavaScript**：クリックに反応したり、表示を変えたりする、ブラウザー上のプログラミング。
- **PHP**：サーバーで処理し、動的なWebページを届けるしくみ。

## サイトの特徴

### レッスンごとに学習

言語別のカードからレッスンのアコーディオンを開き、GitHubのソースコード、実行ページ、YouTubeの動画へのリンクを確認できます。コードと動作を見比べながら、理解を深めていく構成です。

### その場でコードを体験

トップページには、名前を入力してJavaScriptを実行できる体験コーナーがあります。入力に応じて挨拶が変わる、小さなプログラムから学習を始められます。

### 短いサンプルで基礎を知る

見出しの作成と色の指定、クリックによる表示の変更、PHPによる文章の出力など、各言語の役割がわかる入門例を掲載しています。

### 気軽に立ち寄れるデザイン

空をイメージした青を基調に、犬と芝のイラストをあしらっています。スマートフォンでも読み進めやすいレイアウトで、学習への第一歩を後押しします。

## こんな方に

- Webサイトづくりを始めてみたい方
- HTML・CSS、JavaScript、PHPの役割を知りたい方
- 小さなコードを試しながら学びたい方

レッスンやサンプルは順次充実させていく予定です。はじめての一行から、できることを少しずつ広げていきましょう。
